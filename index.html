    Settings

    Google key is optional. Without it the app uses free OpenStreetMap data, which works well for most Australian addresses but is slower. A Google key makes address matching faster and more accurate.

    Put the app online to share links

    Links open on other devices only when the app is online. It is free. Addresses travel inside each link and are never stored on the website.

    1. Open app.netlify.com/drop in Chrome or Edge.
    2. Drag the whole AddressSorter folder onto the page.
    3. Copy the web address it gives you (it ends in .netlify.app).
    4. Click Claim and sign up free. Without this the site expires.
    5. Paste the address below and press Save address.

    How to get a Google key

    1. Go to console.cloud.google.com and sign in with a Google account.
    2. Click the project menu at the top, choose New project, then Create.
    3. Open the menu (three lines) > Billing and add a payment card. Google requires this, and a free monthly allowance applies.
    4. Open APIs & Services > Library, search Geocoding API, click it, then Enable.
    5. Open APIs & Services > Credentials > Create credentials > API key. Copy the key.
    6. Click Edit API key, under API restrictions pick Geocoding API, and save. Leave website restrictions on None.
    7. Paste the key above and press Save key.
